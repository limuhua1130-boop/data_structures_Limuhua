# task2：英文排版大纲

逐字符读词，攒成一行，再处理分段和分页

### 文件

- `formatter.h`：结构、常量、函数声明
- `formatter.c`：排版实现
- `main.c`：测试

### 排版设置

- `Indent`：段首缩进 4 格
- `Page_len`：每行 80 字符
- `Page_num`：每页 30 行

### State：排版状态

| 成员 | 作用 |
| --- | --- |
| `cur` | 当前行字符串 |
| `len` | 当前行长度 |
| `page_lines` | 本页已输出行数 |
| `pages` | 当前页码 |

### formatter.c 里的函数

| 函数 | 作用 |
| --- | --- |
| `state_init` | 分配空间、归零 |
| `state_clear` | 释放空间、清零 |
| `read_next` | 逐字符读词 |
| `is_cap` | 判断能否放下 |
| `add` | 拼词、补空格和缩进 |
| `output` | 输出当前行、必要时换页 |
| `write_direct` | 空行或长词直接输出 |
| `func` | 整体排版 |

`read_next` 把词写进传入的 `word`，返回遇到的分隔情况：

- `1`：空格
- `2`：换行
- `3`：输入结束

拿到返回码时，`word` 里也可能有词，要先处理这个词

### func 里的标记

| 变量 | 记什么 |
| --- | --- |
| `first` | 是否为段落首词 |
| `input_line_has_text` | 当前输入行是否有词 |
| `in_para` | 当前是否处于段落中 |
| `pending_blank` | 是否待补段间空行 |

### 大致流程

1. `state_init`：准备当前行
2. 分配 `word`：准备单词空间
3. `read_next`：读词
4. `is_cap`：看看放不放得下
5. 放得下就 `add`，放不下先 `output` 再放
6. 空行分段，多空行合成一个段间空行
7. 输出满页后，下一行前加 `\f` 换页
8. 输入结束，输出剩余内容，释放空间

首词加缩进后仍放不下时，用 `write_direct` 单独输出
